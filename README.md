# Cascada de los Ángeles

Proyecto freelance para una empresa de distribución de agua. Incluye un sistema de gestión y una página web comercial.

## Sistema de gestión

- Gestión de clientes, pedidos y ventas.
- Control de stock por sucursal.
- Carga de camiones y seguimiento de entregas.
- Registro y aprobación de rendiciones.
- Acceso a funciones según el rol del usuario.

Tecnologías: React Native, Expo, TypeScript, Supabase y PostgreSQL.

## Página web

Desarrollo de la web comercial para presentar la empresa, sus productos y medios de contacto.

Tecnologías: React y Vite.

## Mi participación

Relevamiento de requerimientos, desarrollo de la página web y la aplicación, implementación del backend y diseño de la base de datos.

## Sobre este repositorio

Presentación del proyecto y sus funcionalidades. El código fuente se mantiene privado.
